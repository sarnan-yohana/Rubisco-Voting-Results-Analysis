# Rubisco Voting Results Analysis

## Project Overview
This project analyzes voting data from the Rubisco Awards to understand voting
patterns, category performance, and top nominees.

## Business Problem
The organizers needed a transparent way to:
- Count total votes accurately
- Identify top-performing nominees
- Understand category-level engagement

## Tools Used
- Microsoft Excel (data cleaning)
- SQL (data analysis and aggregation)
- Power BI (dashboard and visualization)

## Objectives
- Clean and prepare raw voting data
- Analyze votes using SQL queries
- Build an interactive Power BI dashboard
- Generate insights to support decision-making

## Data Cleaning
- Removed duplicates
- Standardized nominee names
- Fixed category inconsistencies

## SQL Analysis
- Total votes per nominee
- Votes by category
- Top nominees ranking

## Power BI Dashboard
- KPI cards for key metrics
- Bar chart of top nominees
- Donut chart of votes by category
- Interactive slicers

## Key Insights
- Dajin Sarnan Yohana received the highest number of votes
- Voting engagement varied across categories
- Few categories dominated overall participation

## Conclusion
This project demonstrates practical data analytics skills including data cleaning,
SQL analysis, and visualization using Power BI.
